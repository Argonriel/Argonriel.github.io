MATH 131A · Real Analysis I

Root test

thmanalysis/series

Theorem

Put α=lim supn→∞|an|1/n∈[0,+∞].

  • α<1: ∑an converges absolutely.
  • α>1: ∑an diverges.
  • α=1: inconclusive.

Proof sketch: if α<q<1, eventually |an|≤qn, so use Comparison test. If 1<q<α, infinitely many terms satisfy |an|>qn and hence an↛0.

At α=1: ∑1/n diverges, while ∑1/n2 converges.

The Ratio test implies the corresponding root-test conclusion when ratios are defined eventually; the converse fails. See that note for an example.
