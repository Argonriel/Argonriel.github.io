MATH 131A · Real Analysis I

IVT

thmanalysis/continuity

Theorem

Let a<b and f:[a,b]→R be continuous. If min{f(a),f(b)}≤y≤max{f(a),f(b)}, then some x∈[a,b] satisfies f(x)=y.

Connectedness formulation: a continuous real-valued map on an interval has interval image (a singleton is allowed). For [a,b], compactness additionally makes that image a closed bounded interval.

Consequences

  • Every real polynomial of odd degree has a real root: values at sufficiently large positive and negative inputs have opposite signs.
  • If f is continuous and strictly monotone on [a,b], it is a bijection onto its image interval, with continuous inverse.
  • For a strictly monotone function on an interval, having an interval image rules out jump discontinuities and implies continuity.
