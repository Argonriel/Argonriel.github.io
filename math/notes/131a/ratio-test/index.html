MATH 131A · Real Analysis I

Ratio test

thmanalysis/series

Theorem

Assume an≠0 for all sufficiently large n, and set rn=|an+1/an|.

  • lim suprn<1: ∑an converges absolutely.
  • lim infrn>1: ∑an diverges.
  • Otherwise this test is inconclusive.

The conclusions follow from eventual geometric upper/lower bounds on |an|.

Relation to Root test: lim infrn≤lim inf|an|1/n≤lim sup|an|1/n≤lim suprn. Thus a decisive ratio test implies a decisive root test.

Converse fails: take a2k=4−k (k≥1),a2k+1=4−k (k≥0). Ratios alternate between 1 and 1/4, so lim suprn=1 is inconclusive; however |an|1/n→1/2, so the root test gives convergence.
