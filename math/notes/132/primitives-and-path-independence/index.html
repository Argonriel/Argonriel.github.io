MATH 132 · Complex Analysis

Primitives and path independence

defthmcomplex-analysis/integration

Primitive

A primitive of f on an open set is a holomorphic function F satisfying F′=f.

If F is a primitive and γ runs from a to b, then ∫γf(z)dz=F(b)−F(a). Use the chain rule for F∘γ and the real fundamental theorem of calculus on each smooth segment.

For continuous f on a domain D, the following are equivalent:

  • f has a primitive on D;
  • the integral of f depends only on the endpoints;
  • the integral is zero around every piecewise smooth closed path in D.

For the reverse direction, fix z0∈D and define F(z)=∫z0zf(w)dw. Path independence makes this well-defined. On a small disk, compare values using a straight segment; continuity gives F′(z)=f(z). Two primitives on a domain differ by a constant.

Existence theorem: every holomorphic function on a simply connected domain has a primitive, by Cauchy's theorem.

Boundary: 1/z is holomorphic on the punctured plane but has no primitive there, since its unit-circle integral is 2πi. The function 1/z2 does have the global primitive −1/z on that same domain.
