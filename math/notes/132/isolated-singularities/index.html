MATH 132 · Complex Analysis

Isolated singularities

defcomplex-analysis/singularities

Let f be holomorphic on a punctured disk 0<|z−a|<R. The excluded point a is an isolated singularity; classify it using the Laurent expansion on that punctured disk.

Type Negative Laurent coefficients Equivalent local description
Removable All vanish f extends holomorphically across a
Pole of order m≥1 Finitely many nonzero; lowest power is −m f(z)=(z−a)−mg(z), with g holomorphic and g(a)≠0
Essential Infinitely many nonzero Neither removable nor a pole

The negative-power sum is the principal part. A pole satisfies |f(z)|→∞ as z→a; conversely, this limit characterizes a pole among isolated singularities.

Examples at 0: sin⁡zz is removable,1z2 has a pole of order 2,e1/z is essential.

Boundary: the residue is only the coefficient of (z−a)−1. Residue 0 does not imply removability: 1/z2 is a counterexample. Classification also requires a full punctured neighborhood; a branch point such as 0 for a square-root branch is not an isolated singularity of a single-valued holomorphic function on a punctured disk.
