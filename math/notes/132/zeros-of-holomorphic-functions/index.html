MATH 132 · Complex Analysis

Zeros of holomorphic functions

defthmcomplex-analysis/holomorphic

Let f be holomorphic near a, with f(a)=0, and not identically zero near a.

Order of a zero

The order is the smallest m≥1 for which f(m)(a)≠0. Equivalently, f(z)=(z−a)mh(z), where h is holomorphic near a and h(a)≠0.

Use the first nonzero coefficient in the Taylor series. Continuity keeps h nonzero on a smaller disk, so a is an isolated zero. The orders of zeros add under multiplication.

Isolated zeros theorem: if f is holomorphic and not identically zero on a domain D, every zero in D has finite order and is isolated.

To justify finite order, consider the set where all derivatives vanish. Taylor expansion makes this set open, while continuity of every derivative makes it closed. Connectedness forces it to be empty unless f≡0.

Useful division: if f(0)=0, then f(z)/z extends holomorphically at 0, with value f′(0). This is the step used in Schwarz's lemma.

Boundary: isolated does not mean finitely many zeros on the whole domain; sin⁡z has infinitely many. On any compact subset of D, however, a nonzero holomorphic function has only finitely many zeros, since an infinite set would have a limit point inside D.
