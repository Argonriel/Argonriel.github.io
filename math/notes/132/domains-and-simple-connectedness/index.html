MATH 132 · Complex Analysis

Domains and simple connectedness

defcomplex-analysis/topology

Domain

A domain D⊆C is nonempty, open and connected.

Every domain in C is polygonally path connected. For a fixed point, the set of points reachable by polygonal paths is open, and its complement in D is open; use connectedness.

A domain is simply connected if every continuous closed curve can be continuously contracted to a point while staying inside D.

A domain is star-shaped about a∈D if a+t(z−a)∈D(z∈D, 0≤t≤1). Contract each loop along these segments to obtain convex⟹star-shaped⟹simply connected.

Disks and C are simply connected. The punctured plane and an annulus r<|z|<R, with 0<r<R, are connected but not simply connected: a circle around the missing center cannot contract there.

Why it matters: holomorphic functions on a simply connected domain have primitives. A particular function can have a primitive on a domain with holes; for example, 1/z2 has primitive −1/z on the punctured plane.
