MATH 132 · Complex Analysis

Essential singularities

defthmcomplex-analysis/singularities

An isolated singularity is essential when its Laurent principal part has infinitely many nonzero terms.

Example: e1/z=∑n=0∞1n!zn(z≠0). It has an essential singularity at 0. Along positive real z→0 it tends to infinity, while along negative real z→0 it tends to 0.

Casorati-Weierstrass

If a is an essential singularity of f, then the image of every sufficiently small punctured disk 0<|z−a|<r is dense in C.

Proof idea: if the image missed a disk D(w,ε), then g(z)=1f(z)−w would be bounded on that punctured disk. Extend g across a using the removable singularity theorem. If g(a)≠0, then f=w+1/g extends holomorphically. If g(a)=0, its zero has finite order, so f has a pole. Both contradict essentiality.

Boundary: dense image does not mean every value is attained; e1/z never equals 0. The conclusion concerns every small punctured neighborhood, not merely the image on some large domain.
