Schwarz lemma

Let f be holomorphic on D={z:|z|<1}, with |f(z)|≤1 and f(0)=0. Then |f(z)|≤|z|,|f′(0)|≤1. If equality holds at some z≠0, or if |f′(0)|=1, then f(z)=λz with |λ|=1.

Proof: the zero at 0 allows the holomorphic extension g(z)={f(z)/z,z≠0,f′(0),z=0. For |z|<r<1, the maximum modulus principle on the radius-r disk gives |g(z)|≤max|w|=r|g(w)|≤1r. Let r↑1 to get |g|≤1. Either equality assumption makes |g| attain its maximum at an interior point, so g≡λ.

Boundary: equality |f(0)|=|0| is automatic and gives no rigidity. For example, f(z)=z2 satisfies the hypotheses but is not a rotation.

Disk Möbius maps move a chosen point to 0, making this normalized theorem useful for other base points.
