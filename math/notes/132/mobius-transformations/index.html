Fractional linear transformation

T(z)=az+bcz+d,a,b,c,d∈C,ad−bc≠0.

For c≠0, set T(−d/c)=∞ and T(∞)=a/c. For c=0, T is affine and T(∞)=∞. This makes T a bijection of C^, with inverse T−1(w)=dw−b−cw+a.

The matrix (abcd) determines T up to multiplication by a nonzero scalar. Composition corresponds to matrix multiplication in the same order. At finite non-pole points, T′(z)=ad−bc(cz+d)2≠0.

Three-point theorem: for any ordered triple of distinct sphere points (z1,z2,z3) and another such triple (w1,w2,w3), there is exactly one Möbius map sending each zj to wj.

For finite distinct zj, the map S(z)=(z−z1)(z2−z3)(z−z3)(z2−z1) sends them to (0,1,∞). Use limits if one point is infinity, then compose with the inverse of the corresponding map for the target triple.

Examples: (z−i)/(z+i) sends (0,i,∞) to (−1,0,1). If |a|<1, then ϕa(z)=z−a1−a―z,1−|ϕa(z)|2=(1−|a|2)(1−|z|2)|1−a―z|2. Thus ϕa maps the unit disk to itself and its boundary to itself; its inverse is (w+a)/(1+a―w).
