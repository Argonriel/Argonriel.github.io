MATH 132 · Complex Analysis

Contour integrals

defcomplex-analysis/integration

Let γ:[a,b]→C be a piecewise C1 path and f continuous on its image.

Complex line integral

∫γf(z)dz=∫abf(γ(t))γ′(t)dt.

For f=u+iv and z=x+iy, f(z)dz=(udx−vdy)+i(vdx+udy). The definition is independent of an orientation-preserving piecewise smooth reparametrization. Reversing the path changes the sign; concatenation adds the integrals.

Arc length instead uses L(γ)=∫ab|γ′(t)|dt=∫γ|dz|. The complex element dz records direction; |dz| measures length.

Circle example: for the positively oriented circle γ(t)=a+reit, 0≤t≤2π, with r>0, ∫γ(z−a)mdz={2πi,m=−1,0,m∈Z∖{−1}. Substitute dz=ireitdt and integrate irm+1ei(m+1)t. Traversing the circle clockwise reverses the result; multiple traversals multiply it by the signed number of turns.

Boundary: a closed path does not by itself make a contour integral zero. The case m=−1 is the basic obstruction to a global primitive.
