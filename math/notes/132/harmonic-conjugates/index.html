MATH 132 · Complex Analysis

Harmonic conjugates

defthmcomplex-analysis/harmonic

Let u be real harmonic on a domain D.

Harmonic conjugate

A real function v is a harmonic conjugate of u if u+iv is holomorphic, equivalently vx=−uy,vy=ux.

The form ω=−uydx+uxdy is closed because −uyy=uxx. On a simply connected domain, it is exact, so v(z)=v(z0)+∫z0zω is well-defined and is a harmonic conjugate. Every harmonic function therefore has conjugates locally, and has one globally if the domain is simply connected. Any two global conjugates on a domain differ by a real constant.

Example: for u(x,y)=xy, integrate vx=−x, vy=y: v(x,y)=y2−x22+C,u+iv=−i2z2+iC.

Boundary: u(z)=log⁡|z| is harmonic on C∖{0}, but its conjugate form has integral 2π around the unit circle. A global conjugate would make this integral zero. Locally the conjugate is a branch of the argument.
