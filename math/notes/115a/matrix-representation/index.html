MATH 115A · Linear Algebra I

Matrix representation

deflinear-algebra/maps

Let T:V→W be linear, with ordered bases β=(v1,…,vn) and γ=(w1,…,wm).

Columns are images

[T]βγ=[[T(v1)]γ⋯[T(vn)]γ]∈Mm×n(F). [T(v)]γ=[T]βγ[v]β.

There are n columns, one per input basis vector, and m rows, one per output coordinate. “用输出的基，凑出输入基向量的像。”

If S:W→U and δ is a basis of U, then [S∘T]βδ=[S]γδ[T]βγ. The middle basis must agree for ordinary matrix multiplication to describe composition.

Example: for D:P2(R)→P1(R), using (1,x,x2) and (1,x), [D]=(010002).

A matrix describes a map and a choice of bases. Changing the bases changes the matrix, not the underlying map.
