MATH 115A · Linear Algebra I

Linear map

deflinear-algebra/maps

Let V,W be vector spaces over the same field F.

Definition

T:V→W is linear if T(au+bv)=aT(u)+bT(v)(a,b∈F, u,v∈V).

Every linear map sends 0 to 0 and preserves finite linear combinations. An operator is a linear map T:V→V.

Basis principle: assigning arbitrary images T(vj)=wj to a basis of V determines a unique linear map: T(∑jajvj)=∑jajwj. This is why the columns of a matrix record basis-vector images.

Examples: differentiation on polynomials, evaluation f↦f(a), and integration f↦∫abf on C([a,b],R).

Counterexamples: a nonzero translation is not linear. Complex conjugation is R-linear but not C-linear.

Linearity alone does not imply continuity in infinite-dimensional normed spaces. For example, differentiation on polynomials with the sup norm on [0,1] is unbounded: ‖xn‖∞=1 but ‖(xn)′‖∞=n.
