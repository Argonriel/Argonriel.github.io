MATH 115A · Linear Algebra I

Span and linear independence

deflinear-algebra/foundations

For S⊆V, span⁡S={∑j=1majvj:m≥0, aj∈F, vj∈S}. Only finite linear combinations are used, even when S is infinite. In particular, span⁡∅={0}.

Linear independence

A finite list (v1,…,vm) is independent if ∑j=1majvj=0⟹a1=⋯=am=0. It is dependent if a nontrivial choice of coefficients gives 0.

An arbitrary set is independent when every finite subset is independent. A list containing 0, or containing a repeated vector, is dependent.

Useful test: a dependent list has a vector in the span of the others. Solve a nontrivial relation for a vector whose coefficient is nonzero.

Independence gives uniqueness of coefficients; spanning gives existence. Together they give a basis.

Function example: 1,x,…,xm are independent as real-valued functions on R, because a polynomial that vanishes everywhere has all coefficients zero.
