MATH 131B · Real Analysis II

Lipschitz continuity

defanalysis/continuity

Definition

A map f:(X,dX)→(Y,dY) is Lipschitz if some finite L≥0 satisfies dY(f(x),f(y))≤LdX(x,y)∀x,y∈X.

Lipschitz⟹uniformly continuous⟹continuous.

Proof of first arrow: if L>0, choose δ=ε/L. If L=0, the map is constant (on a nonempty domain) and any positive δ works.

Converses fail

  • f(x)=x on [0,1] is uniformly continuous by Heine–Cantor, but |f(x)−f(0)|/|x|=1/x→∞.
  • f(x)=1/x on (0,1) is continuous but not uniformly continuous; see Continuity.

Practical sufficient condition: if f is differentiable on an open interval I and |f′|≤L there, MVT gives |f(x)−f(y)|≤L|x−y| for x,y∈I. Include interval endpoints when f extends continuously to them.
