MATH 131B · Real Analysis II

Connectedness

defthmanalysis/topology

Let E be a metric space, or a subset with its induced metric.

Definition

E is disconnected if E=U∪V for disjoint, nonempty sets U,V open relative to E. Otherwise E is connected.

In R: a nonempty subset is connected iff it is an interval, allowing singletons. The empty set is also connected by the definition.

Continuous images preserve connectedness

If E is connected and f:E→Y continuous, then f(E) is connected.

Proof: a separation of f(E) pulls back to a separation of E.

For a real-valued continuous map on [a,b], this gives IVT: the image is an interval, so it contains every value between f(a) and f(b).

Path connectedness

E is path connected if for any x,y∈E there is a continuous γ:[0,1]→E with γ(0)=x, γ(1)=y.

path connected⟹connected. The converse holds for subsets of R (use the line segment inside an interval). It fails in R2: the topologist's sine curve E={(x,sin⁡(1/x)):0<x≤1}∪({0}×[−1,1]) is connected but not path connected. The oscillating graph is connected and its closure is E; there is no path from the vertical segment to the graph.
